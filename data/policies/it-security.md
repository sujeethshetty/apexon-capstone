# IT Access and Security Standard

## Accounts and authentication
Northstar Labs is a fictional company. Multi-factor authentication is mandatory for every company account that supports it. Shared personal passwords and shared user accounts are prohibited. Use the company-managed password manager for work credentials.

## Access requests
Request application access through ServiceDesk. The line manager confirms the business need and the application owner approves the requested role. IT provisions approved access. Standard approved access requests have a target of 2 working days; this is a service target, not a guaranteed completion time. Use the minimum role needed for the task.

## Remote access and restricted data
Use a company-managed laptop. Connect to the company VPN before accessing internal-only systems from outside the office. Do not upload restricted company data to personal cloud storage or unapproved AI services. No passwords, API keys, or authentication tokens belong in support tickets or assistant questions.

## Security incidents
Report a suspected security incident immediately through the Security Incident form in ServiceDesk. If ServiceDesk is unavailable, call the internal Security hotline listed in the employee directory. This document intentionally does not provide a telephone number. Preserve relevant evidence and do not attempt your own investigation.
